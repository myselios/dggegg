# 제품 개선 제안 — "스프레드시트보다 편한" 1인 과외 강사 OS

작성: 2026-07-13. 근거: 전체 코드베이스 기능 인벤토리 (라우트 9개, 도메인 모델 12개, 컴포넌트 전수 조사).

## 핵심 진단 — 왜 시트를 계속 쓰는가

주 사용자(1인 IB 과외 강사)가 시트로 돌아가는 이유는 기능 부족이 아니라 **입력 비용**이다:

| 작업 | 시트 | 현재 앱 |
|---|---|---|
| 매주 화 4시 고정 수업 등록 | 행 복사 1번 | 매주 슬롯 클릭 → 모달 → 저장 반복 |
| 점수 하나 수정 | 셀 클릭 → 타이핑 | 상세 → 프로필 탭 → 수정 → 저장 (4클릭+) |
| 여러 학생 상태 일괄 변경 | 드래그 채우기 | 불가능 (한 명씩) |
| 전체 학생 정렬·비교·내보내기 | 기본 기능 | 없음 (카드 그리드만, 내보내기 없음) |

**전략: 두 축을 동시에.** ① 입력 비용을 시트 수준으로 낮추고(표 뷰·반복 일정·인라인 편집), ② 시트가 절대 못 주는 가치(수업→학부모 메시지 자동 생성, 회차·정산 자동 카운트, 리마인드)를 얹는다. ②가 진짜 락인이다.

## Tier 1 — 입력 비용 제거 (시트와 동급 만들기)

### 1-1. 반복 수업 UI 연결 ★ 최우선·최소 비용
`createRecurringEvents`(app/actions/schedule.ts:205)와 recurrence 필드가 **이미 구현돼 있으나 UI가 호출하지 않는 데드코드**. 수업 생성 모달에 "매주 반복 · 종료일/횟수" 옵션 하나만 붙이면 과외의 기본 패턴("매주 화 16:00")이 등록 1번으로 끝난다. 반복 수업의 단건 수정/전체 수정 선택(이번 회차만 vs 이후 전체)도 함께.

### 1-2. 학생 "표 모드" (시트 뷰) + 내보내기
카드 그리드와 토글되는 테이블 뷰: 정렬(이름/학교/과정/점수/상태), 셀 인라인 편집(점수·상태·학년), 다중 선택 후 일괄 상태 변경. CSV **내보내기** 추가(현재 가져오기만). CSV 가져오기에 "기존 학생 업데이트" 모드 추가. — "시트가 더 편해"라는 말의 직접적 해답.

### 1-3. 대시보드 원탭 수업 마감
오늘 수업 카드에서 바로: [완료 ✓] [노트 입력] [점수 입력]을 카드 안 인라인으로. 현재는 스케줄 → 블록 클릭 → Sheet → 토글 열기까지 4단계. 하루 끝나고 침대에서 폰으로 30초에 오늘 수업 3개 마감이 가능해야 한다.

### 1-4. 잔손질 (반나절 묶음)
- 학생 상세 "자료" 탭이 빈 플레이스홀더 → 교재/진도(이미 있는 student-materials)와 연결
- 과정 필터에 IGCSE/MYP/기타 누락 보정, 상태 변경(휴원/종료) UI 노출
- weakness_areas·색상 편집 UI

## Tier 2 — 시트가 못 주는 가치 (1인 강사 특화)

### 2-1. 수업 후 학부모 리포트 원클릭 ★ 킬러 기능
수업 완료 시 수업노트(오늘 한 것/숙제/다음 목표) + 최근 점수를 메시지 템플릿에 자동 치환 → **"카톡용 복사" 버튼**. 템플릿 보관함과 수업노트가 이미 각각 존재하므로 "연결"만 하면 된다. 학부모 소통이 과외 재계약의 핵심인데, 이건 시트로 절대 못 한다.

### 2-2. 회차·정산 관리 (Enrollment 활성화)
Enrollment 타입만 있고 미구현. 1인 강사의 최대 고통은 "이번 달 몇 회 했더라": 패키지(예: 8회) 등록 → 완료 수업이 자동 카운트 → "6/8회, 다음 주 정산 안내 시점" 배지 → 정산 안내 메시지도 2-1 템플릿으로 생성. no_show/보강도 회차에 반영.

### 2-3. 주간 브리핑 & 리마인드
매주 일요일 밤 "이번 주: 수업 12개, 정산 임박 2명, 지난주 노쇼 1건 보강 미정" 요약을 대시보드 최상단 + (선택) 메일. 내일 수업 전날 알림.

### 2-4. 월간 학생 리포트 공유 링크
성적 추이 차트(이미 Recharts로 존재) + 상담 코멘트를 읽기 전용 링크/PDF로 학부모에게 공유. 프리미엄 과외의 신뢰 장치.

## Tier 3 — 디자인 리프레시 ("요새답게 팬시")

현재: 인디고/바이올렛 글래스모피즘, 완성도는 있으나 밋밋한 지점들. 제안:

1. **다크모드 복구** — `.dark` 토큰이 완비돼 있는데 next-themes 제거로 토글 경로가 없어 사실상 라이트 고정. 토글 하나로 즉시 "요새 앱" 체감. (구현 시 CSS 클래스 방식과 CLAUDE.md의 prefers-color-scheme 기술 불일치도 정리)
2. **대시보드 bento grid** — 오늘 수업·주간 완료율·정산 임박·최근 상담을 크기 차등 타일로. 통계 숫자에 카운트업, 완료 체크에 마이크로 애니메이션.
3. **학생 색상 시스템 활용 강화** — 이미 student.color 필드 존재. 캘린더 블록·카드·차트에 일관 적용해 "내 학생들" 시각 언어 만들기.
4. **모바일 퍼스트 다듬기 + PWA** — 주 사용 시나리오는 수업 직후 폰 입력. 하단 탭 바(현재 햄버거 드로어), 홈 화면 설치(manifest), 원탭 마감(1-3)과 결합.
5. 타이포 위계(숫자는 Geist Mono tabular), 빈 상태 일러스트, 스켈레톤 로딩 통일.
